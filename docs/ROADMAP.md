# 产品路线图

## 定位

「随手工具箱」用于手机上偶尔需要、希望几秒内开始的小任务。围绕一个明确问题做一个完整工具，打开即用。保持清楚的工具目录、独立地址和统一导航。

## 当前版本 · v0.2

- 工具首页和统一站点外壳。
- 「随它转」独立路由：自定义选项、等概率随机、结果展示、自动暂存。
- 第二款工具「单位比价」：2–6 个商品、重量/容量/数量换算、实时比较、分模式自动暂存。
- 工具登记表、独立功能目录、核心逻辑测试、GitHub CI。
- 局域网静态服务，继续保留原有浏览器数据。

## 下一步 · 打磨已有工具

1. 在真实 iPhone Safari 和微信内验证：触屏、键盘、输入恢复、转动后切后台与横竖屏。
2. 已支持最多 30 组命名转盘的保存、载入、更新、删除与撤销；根据反馈继续打磨。
3. 排查依赖审计结果，按可达性和升级兼容性处理；维持构建和核心抽取测试。

## 后续候选顺序

| 优先级 | 方向     | 首个候选 | 最小范围                                     |
| ------ | -------- | -------- | -------------------------------------------- |
| P1     | 随机决策 | 随机分组 | 粘贴名单、指定组数、随机均分、复制结果       |
| P2     | 时间效率 | 专注计时 | 设置时长、开始/暂停/重置；明确后台和通知限制 |
| P3     | 文本处理 | 文本整理 | 字数统计、去空行、逐行去重、复制结果         |

这些是候选，尚未实现，不在首页展示为可用工具。每次只完成一个工具再推进下一个。

## 扩展边界

- 新工具优先在浏览器本地处理数据；引入联网或同步前明确目的、保存范围及用户提示。
- 工具少时用简单目录，不急于增加搜索、分类筛选、账号、收藏和后台管理。
- 公网站点已改用 GitHub Pages，通过 main 分支自动发布；继续验证微信真机访问，自定义域名后置。
- PWA 和离线缓存后置，先明确 iPhone 的使用方式、缓存更新及数据清理行为。

## 新工具完成标准

主流程完整；输入边界和错误反馈明确；手机可用且键盘可操作；独立标题和地址；数据行为有说明；相关自动检查通过；真机验证状态如实记录。
